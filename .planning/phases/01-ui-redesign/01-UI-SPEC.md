# Phase 1 — UI Design Contract: Neo-Brutalism CommunityHub

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|:---|:---|
| **Paradigm** | Neo-Brutalism (Bold 2px/3px Black Borders, Hard Drop Shadows, Tactile Geometry) |
| **Tool** | Tailwind CSS + Custom Token Classes |
| **Preset** | Neo-Brutalism Pastel Web Directory |
| **Component Architecture** | Astro SSG Components (Zero JS hydration unless interactive) |
| **Icon Library** | Heroicons (Outline, 2.5px stroke width for chunky Brutalist aesthetic) |
| **Font Family** | Sans-Serif system stack (system-ui, Roboto, Arial) with 900 Black headlines and bold body weights |

---

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|:---|:---|:---|
| **xs** | 4px (gap-1, p-1) | Badge icon gaps, inline tag margins |
| **sm** | 8px (gap-2, p-2) | Navigation items, badge padding, platform pill gaps |
| **md** | 16px (gap-4, p-4) | Standard grid spacing, card internal padding, form input spacing |
| **lg** | 24px (gap-6, p-6) | Community card body padding, hero internal padding, filter bar spacing |
| **xl** | 32px (gap-8, p-8) | Hero block padding, major section gaps |
| **2xl** | 48px (py-12) | Standard section vertical rhythm |
| **3xl** | 64px (py-16 / py-20) | Page hero vertical padding, footer vertical bounds |

*Exceptions:* Hard shadow offsets are 1.5px (badges), 3px (buttons), 4px (cards), and 6px (hero container/forms).

| **Sticker Badges** | 10px-11px | 900 (Black) | 1.0 | text-[10px] sm:text-[11px] font-black uppercase tracking-wider |

## Color Palette (60-30-10 Rule)

| Role | Hex | Tailwind Token | Usage |
|:---|:---|:---|:---|
| **Dominant (60%)** | #FAF8F5 | bg-[#FAF8F5] | Canvas background, warm retro paper surface |
| **Secondary (30%)** | #FFFFFF | bg-white border-2 border-black | Standard cards, search bar container, header, input fields |
| **Accent Primary (10%)** | #A7F3D0 / #D1FAE5 | bg-[#A7F3D0] (Pastel Mint) | Hero block, primary submit CTA buttons, '+ Submit Listing' |
| **Accent Secondary** | #FEF08A / #FEF9C3 | bg-[#FEF08A] (Butter Yellow) | Search button, logo square, CMD+K badge, verified stats counters |
| **Platform Pastel: Discord** | #DDD6FE / #EDE9FE | bg-[#DDD6FE] (Lilac) | Discord badges, Discord platform filter pills |
| **Platform Pastel: Telegram** | #BAE6FD | bg-[#BAE6FD] (Sky Blue) | Telegram badges, Telegram platform filter pills |
| **Destructive / Danger** | #FECDD3 / #FFE4E6 | bg-[#FECDD3] (Soft Coral) | Report listing headers, moderation flags, danger warnings |

**Accent Reserved For:** Primary conversion actions (+ Submit Listing, Join Now), high-emphasis sticker badges (★ 100% REAL LINKS ★), and verified metadata highlights.

## Hard Drop Shadow Contract

| Shadow Level | CSS Box Shadow Rule | Usage Target |
|:---|:---|:---|
| **Micro Shadow** | shadow-[1.5px_1.5px_0px_0px_#000] | Platform badges, category pills, verification tags, keyboard shortcuts |
| **Interactive Button** | shadow-[3px_3px_0px_0px_#000] | Tactile buttons (compresses to 0px on :active) |
| **Card Shadow** | shadow-[4px_4px_0px_0px_#000] | Community listing cards, category summary boxes, search input dock |
| **Container Shadow** | shadow-[6px_6px_0px_0px_#000] | Hero hero container, submit form card, report card |
